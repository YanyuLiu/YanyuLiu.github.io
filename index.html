Selected work · 01

Evaluating Meta Muse Agent Mandate Adherence

Can a personal AI agent remain useful while reliably staying within the authority granted by the user?

Project summary

A product-level evaluation protocol for Meta Muse built around 30 scenarios across three behavioral dimensions and five safety–utility metrics. The dataset is designed to reveal whether Muse stays within user-granted authority, resists indirect prompt injection, and asks for confirmation before consequential actions; evaluation results have not yet been collected.

Selected work · 02

Agent Evaluation Framework Prompt Injection & Tool Misuse

How reliably can a tool-using AI agent complete legitimate tasks while resisting adversarial instructions and unauthorized actions?

Project summary

Across 50 cases and 150 gpt-4o-mini runs, layered safeguards reduced attack success from 28.9% at baseline to 10.5% while legitimate task success held at 90.5% and measured over-refusal stayed at 0%. Indirect injection and unauthorized tool use fell to 0% in the strongest configuration, while sensitive-data exfiltration remained the hardest category at 50% attack success.

50evaluation cases
5test categories
3agent configurations

System comparison

Measure safety, utility, and calibration together.

A lightweight Python harness compares a baseline agent, explicit instruction hierarchy, and hierarchy plus a deterministic permission gate.
